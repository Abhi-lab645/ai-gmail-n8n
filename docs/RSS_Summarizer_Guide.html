3. Docker Deployment Instructions

n8n runs containerized with persistent state in Docker volume n8n-class_n8n_data.

Docker Compose (Recommended)

# Start n8n in detached mode
docker compose up -d

# Verify container is healthy
docker compose ps

# Import all workflows into container
chmod +x ./scripts/import-workflow.sh
./scripts/import-workflow.sh
Persistent Storage Architecture
All n8n credentials, SQLite databases, and workflow definitions reside in the external Docker volume n8n-class_n8n_data mounted at /home/node/.n8n. Updating, stopping, or restarting the Docker image preserves all configurations.

4. Authentication & Credentials Setup

A. OpenRouter AI Setup

1. Sign in to openrouter.ai/keys and generate a free API key.
2. In n8n, navigate to Credentials → Add Credential → OpenRouter API and paste the key.
3. The workflow uses model openrouter/free, which routes to high-quality free community models.

B. Google Cloud OAuth2 Setup

To enable n8n to append and update records in Google Sheets:

  1. Enable Google APIs: In Google Cloud Console, enable both Google Sheets API and Google Drive API.
  2. OAuth Consent Screen:
    • User Type: External.
    • Under Test users, click + Add Users and input your Google email. (Failing to do this triggers Error 403: access_denied).
  3. Create OAuth Credentials:
    • Application type: Web application.
    • Authorized Redirect URI: http://localhost:5678/rest/oauth2-credential/callback.
  4. Google Sheet Destination: Create a sheet titled RSS Summaries with row 1 headers: Source | Title | Link | Published | Summary.

6. Production Troubleshooting Matrix

Symptom Root Cause Resolution
Single feed fetches same 5 items Feed has not updated since last run; static Limit takes top 5. Use rss-summarizer-multi.json. It checks 4 sources and deduplicates via appendOrUpdate.
Error 403: access_denied Google OAuth in Testing mode without email in Test Users. Add Google account in Google Cloud Console → OAuth consent screen → Test users.
Google Drive / Sheets API Disabled APIs not activated in Google Cloud project. Enable Google Sheets API and Google Drive API in Google Cloud Library.
columns.schema required n8n v4.4+ requires column schema metadata in defineBelow mode. All workflow files in workflows/ include the full schema definitions matching the sheet.
OpenRouter 429 Rate Limit High traffic on free model tier. Workflow nodes include 3 automated retries with 2000 ms backoff.
